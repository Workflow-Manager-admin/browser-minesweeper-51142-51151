# browser-minesweeper-51142-51151

## Minesweeper Frontend (Vite + Svelte)

This is a browser Minesweeper game using Vite and Svelte.

**Tech stack:**  
- Vite  
- Svelte (minimal, single-file components)  
- Responsive, minimalist, modern style

### Features
- Choose difficulty or customize the grid
- Responsive game board for mobile and desktop
- Timer, mines left, win/loss indicator
- Restart/Reset
- Mouse (left/right)/touch input

### Getting Started

Install dependencies:
```
npm install
```

Run the development server:
```
npm run dev
```
